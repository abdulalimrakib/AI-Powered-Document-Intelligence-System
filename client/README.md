# AI-Powered Document Intelligence System — Client

Next.js 15 (App Router) web UI for the AI-Powered Document Intelligence System: upload documents, monitor processing, review and correct extracted data, and search.

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL = backend URL
npm run dev                  # http://localhost:3000
npm run lint && npm run build
```

Stack: React 19, TypeScript, Tailwind CSS 4, shadcn/ui, next-themes, sonner.
